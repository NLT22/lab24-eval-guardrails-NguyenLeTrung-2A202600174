Monthly Cost Breakdown (~100k queries/month)

3 Alert Playbooks

Playbook 1: Faithfulness Drop
Trigger: F < 0.70 trong cửa sổ 1 giờ · Nguyên nhân: top-k quá thấp, prompt bị sửa, model rollback · Fix: tăng top-k lên 5, thêm evidence-only prompt constraint
Playbook 2: L1 Latency Spike
Trigger: L1 P95 > 200ms · Nguyên nhân: embedding model cold-start (process restart hoặc idle timeout) · Fix: keepalive ping mỗi 60s, hoặc chuyển sang Groq Llama Guard free tier
Playbook 3: PII Detection Drop
Trigger: PII rate < 90% trong daily test · Nguyên nhân: Presidio model không load, regex pattern bị comment out · Fix: fallback sang rule-based-only mode, alert on-call

Architecture — Defense-in-Depth Pipeline

User Query  → L1: PII Redaction + Topic Validation  → L2: Qdrant Hybrid Search (BM25 + dense, reranker)  → L2b: LLM Generation (OpenAI / LM Studio)  → L3: Llama Guard Output Safety (HF → LM Studio → rule-based)  → L4: Async Audit Log  → Response
